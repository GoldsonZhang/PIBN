Minimum Functional Asset for Rice AGB Estimation Framework
==========================================================

1. OVERVIEW
-----------
This package contains a "Functional Demo" of the proposed framework.
It includes the source code for the Dual-Branch Deep Feature Extraction 
and CatBoost regression pipeline.

2. DATA AVAILABILITY NOTE
-------------------------
Due to the massive size of the full dataset (TB-level) and privacy constraints, 
we provide a small set of "Sample Imagery" in the `sample_data/` folder.

**IMPORTANT:** The purpose of this package is to allow reviewers to audit the code logic, 
verify the deep learning architecture, and ensure the pipeline runs without errors.
The numerical results (R2/RMSE) generated by this demo are NOT representative 
of the study's full results, as the sample size is insufficient for training 
deep learning models.

3. CONTENTS
-----------
- demo_pipeline.py  : The main script to load images, extract features, and run the model.
- sample_data/      : Folder containing sample RGB and Multispectral images.
- requirements.txt  : Python dependencies.

4. HOW TO RUN
-------------
1. Install dependencies:
   pip install -r requirements.txt

2. Run the pipeline:
   python demo_pipeline.py

5. EXPECTED OUTPUT
------------------
The script will:
1. Load the sample images from `sample_data/`.
2. Pass them through the EfficientNet (RGB) and ResNet (MCA) backbones.
3. Print the shape of the extracted feature matrix.
4. Perform a trial training run to confirm the regression module works.
